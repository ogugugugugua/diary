Xingji Sans Regular is a static weight-400 instance of Noto Sans SC.

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
Original variable font: NotoSansSC[wght].ttf
License: SIL Open Font License 1.1, reproduced in OFL.txt.

Generated using fontTools 4.61.1 varLib.instancer with wght=400.
The derivative family and PostScript names were changed to Xingji Sans
and XingjiSans-Regular. Copyright and license entries were retained.
Used for matching browser print previews and embedded PDF text.

The complete font is stored as checksummed gzip parts in assets/fonts/.
scripts/prepare-assets.mjs restores the identical travel-sans.ttf during
npm install, npm run dev, npm test, or npm run build. No download is needed.
