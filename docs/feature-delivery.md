# 旅行素材到照片书：增量交付

## 1. 行程与拍摄时间

- 新导入照片保留 EXIF 相机时间到秒和可用 UTC 偏移；未知时区不猜测，旧日期继续可读。视频未提取拍摄元数据时支持人工补充。
- 素材详情可补充时刻/时区；行程面板支持批量地点修正和时间偏移。
- 日期＋地点生成候选站点，仅处理未分组素材。站点可编辑故事、排序、合并、拆分或移除；素材原件保持不变。GPS当前显示坐标，未接入地名服务。
- 站点和章节独立关联，从站点追加章节仅使用精选素材和站点故事，不覆盖现有章节。AI写作输入包含行程故事。
- SQLite、JSON/ZIP/文件夹备份恢复保留站点、故事、拍摄时间和章节关联，恢复重映射独立编号。

验证：TypeScript检查、38项自动化检查、正式构建通过。新增测试覆盖时区排序、无效日期、增量分组、拆分及备份恢复关联。浏览器安装下载收到损坏压缩包，尚未完成此阶段浏览器验收。

## 2. 相似照片与并排选片

- 本地按需建立64位画面差异指纹，结合颜色与比例查找近似候选；提供严格/标准/宽松阈值。使用度量树查找，避免全量两两比较；分组以代表照片为锚点。
- 连拍候选使用完整拍摄时间、地点和3秒相邻间隔；日期缺失不猜测连拍。
- 原图并排比较、同步放大与查看位置；支持0–5星评级、标签、独立入选状态和素材筛选。
- 分批保存分析结果、支持停止与重试、逐项列出失败。来源版本变化后旧指纹失效；不会自动删除照片。
- 标签与评级当前保存在游记素材记录中，跨游记不会自动同步。

验证：46项自动化测试通过，包含真实EXIF二进制读取、闰日/非法时刻/UTC边界、站点JSON及文件夹恢复、视觉索引畸形输入、颜色和比例排除、过期索引、2万张同画面分组、评级标签备份。类型检查与正式构建通过。浏览器已实测行程分组、故事编辑、章节生成、刷新恢复、真实画面索引、并排比较、评级及标签筛选；补齐第1项界面验收。
