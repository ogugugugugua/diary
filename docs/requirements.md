**家庭游记应用：第一版需求草案**

版本：0.1 · 草案日期：2026-10-12

2026-10-14基础素材管理已经实现，当前交付范围和边界见 [素材管理说明](material-management.md)。本文仍保留后续产品方向，未标注的建议不表示已经实现。

用途：记录本次讨论中确认的产品方向，作为界面设计、技术验证和后续开发的依据。文中标为“建议”或“待验证”的内容仍属于草案。

**1. 已确认的产品方向**

| 项目 | 要求 |
| --- | --- |
| 使用人群 | 用户自己及家人 |
| 主要场景 | 在电脑上整理旅行照片、视频和回忆，制作可保存、可打印的游记 |
| 内容形式 | 照片和文字的比例灵活，每本游记、每个章节可以不同 |
| 素材来源 | 本地文件和百度网盘 |
| AI能力 | 支持用户指定模型，将语音描述整理为游记内容，辅助选片、组织内容和排版 |
| 人工编辑 | 支持调整文字、照片、章节顺序及页面布局 |
| 默认纸张 | A4竖版，210 × 297 mm |
| 最终成果 | 可打印的PDF，以及可继续编辑的游记项目 |

以“一次旅行一本游记”为默认组织方式。旅行素材、个人回忆、文章内容和打印页面之间应保留关联，方便反复整理。

**2. 第一版主流程**

创建旅行 → 导入素材 → 整理时间线并选片 → 语音或文字补充回忆 → 确认提取的信息 → 生成游记初稿 → 调整图文与分页 → 检查打印效果 → 导出PDF并备份项目。

用户也可以先记录回忆，再导入素材；补充回忆和人工编辑应能在任何阶段继续进行。

**3. 核心界面与交互**

| 界面 | 主要操作 | 需要呈现的信息 |
| --- | --- | --- |
| 旅行库 | 新建、打开、继续编辑旅行 | 标题、日期、封面、素材数量、最近编辑时间 |
| 素材整理 | 本地导入、百度网盘导入、分组、选片、补充拍摄信息 | 缩略图、拍摄时间、地点、选中状态、导入进度及失败项 |
| 回忆补充 | 录音、输入文字、关联照片或章节、修正提取结果 | 原始口述、转写文本、时间地点人物等信息、待确认项 |
| 游记编辑 | 生成初稿、编辑文字、拖动图片、切换模板、锁定页面 | 素材列表、章节、实际分页预览、总页数、保存状态 |
| 打印导出 | 调整页边距、预览、处理质量提示、导出及备份 | 纸张设置、清晰度不足的图片、文字溢出、异常空白页 |
| 模型设置 | 配置与测试模型连接 | 服务地址、模型名称、能力类型、连接状态 |

建议游记编辑采用左侧素材、中间页面预览、右侧编辑工具的布局。具体布局由后续原型验证。

**4. 素材导入与整理**

- 支持电脑批量选择文件和拖入文件；导入后显示进度和逐项结果。
- 百度网盘是首个网盘接入目标，通过官方授权选择目录或文件；具体可用接口与权限待验证。
- 在直连能力验证或不可用时，提供“从百度网盘下载到电脑后导入”的可用路径。这是备用方式，不能视为已完成网盘直连接入。
- 根据拍摄时间、已有定位等信息按天或地点分组。缺少信息时允许手动补充；推测信息显示为待确认。
- 对重复、连拍或模糊照片给出候选建议，由用户选择使用哪些素材。
- 视频生成缩略图和代表关键帧，用户可重新选择用于游记的画面。
- 大批量导入支持取消和失败项重试。建议对网盘素材先加载缩略图，用户选定后获取排版所需原文件。
- 编辑只改变游记中的引用与使用方式，不覆盖素材原件。移出游记与删除原文件必须有清楚的区别。
- 常见格式的具体支持范围待技术验证，重点检查手机常见照片格式、视频编码和拍摄元数据。

**5. 语音、信息提取与游记生成**

支持整段旅行口述，也支持选中某张照片、某段视频或某个章节后补充回忆。文字输入与语音输入使用同一套关联方式。

建议处理顺序：

1. 保留原始口述或输入文本，并生成可编辑的转写。
2. 提取日期、地点、人物、事件、感受，以及与素材的关联。
3. 将含糊或相互冲突的信息列为待确认项，允许用户修正。
4. 根据确认的信息、选定素材和文风生成章节及正文。

AI应保留用户提供的事实和个人感受，不将猜测写成确定经历。照片可以提供场景线索，个人感受应以用户表达为依据。初稿应能追溯到相关素材和回忆记录。

模型设置区分语音识别、文字整理与写作；图片理解是可选能力。允许分别配置服务，不假设一个模型具备全部能力。缺少图片理解能力时，仍可使用时间信息和用户口述完成游记。

建议提供简洁纪实、个人日记、家庭旅行等文风，以及按天、按地点或按主题组织章节的选项。默认文风和章节组织方式留给原型验证。

模型调用应显示任务进度、成功或失败状态，并支持重试。费用估算只在服务可提供可靠价格与用量信息时显示。调用前让用户知道哪些素材或回忆会发送给所选服务；密钥使用掩码显示，不写入日志或导出文件。

**6. AI排版与人工编辑**

提供旅行画册、图文游记、文字日记三种模板方向。同一游记允许按章节切换模板，无需设置统一的照片与文字比例。

AI推荐素材、章节、图注及版式，分页由明确的排版规则处理。人工编辑应支持：

- 修改标题、正文和图注。
- 拖动素材，调整图片顺序、大小、裁切和布局。
- 调整章节顺序、插入分页和修改封面。
- 锁定满意的页面或内容，并对指定章节重新生成。
- 撤销编辑，查看可恢复的历史版本。

重新生成应先展示结果，由用户选择应用范围；锁定内容应保留。图片裁切只影响排版中的显示，不改变原文件。

**7. A4打印与PDF导出**

默认A4竖版，四周约20 mm留白，支持调整页边距及增加装订边距。采用保留白边的默认模板，便于家用打印。

编辑预览应显示实际分页和总页数；导出PDF采用同一版式。支持封面、章节页、页码以及可选目录，正文保留可选择的文字并嵌入所需字体。

导出检查覆盖：

- 图片在当前打印尺寸下的有效清晰度是否足够。
- 正文或图注是否溢出、截断，是否出现异常空白页。
- 素材是否缺失，网盘原文件是否获取完成。
- 中文字体和页面元素是否正确呈现。

建议以300 DPI作为图片质量目标，具体提示阈值通过实际打印验证，不承诺放大小图能增加真实细节。

视频在PDF中使用关键帧、连续画面和文字说明。在线播放及二维码需要稳定可访问的视频链接，归入后续能力，不生成无效链接。

**8. 保存、备份与恢复**

游记项目至少保存旅行信息、素材关联、回忆记录、确认后的信息、章节正文、页面布局、锁定状态和打印设置。

- 自动保存，并显示保存状态。
- 备份后可在再次打开时继续编辑，不能只有最终PDF。
- 备份文件不得包含模型密钥或网盘授权令牌。
- 素材路径变化或文件不可用时，显示具体缺失项并允许重新关联。
- 需要区分轻量项目备份和包含所用素材的完整备份；建议提供两者，提示文件大小和恢复条件。

存储方式、备份格式及是否在多个家庭设备间同步，由技术设计确认。第一版不依赖多人同时编辑才能完成主流程。

**9. 第一版验收场景**

| 场景 | 通过条件 |
| --- | --- |
| 从本地素材制作游记 | 能批量导入照片和视频、按时间整理、选择素材，并生成可编辑初稿 |
| 针对照片补充回忆 | 一段录音可关联到指定照片；转写与提取信息可修正，正文使用修正后的信息 |
| 使用自选模型 | 可配置服务并验证连接；语音与写作可分别配置，缺少某项能力时说明可用替代路径 |
| 调整照片与文字比例 | 同一本游记可同时包含大图页面和长文页面，切换模板后内容仍可编辑 |
| 再次生成内容 | 指定章节可重新生成，锁定页面保留，用户可预览并选择应用结果 |
| 导入失败恢复 | 失败文件被列出，成功文件保持可用，重试无需重新导入整批素材 |
| 导出A4 PDF | 页面尺寸为210 × 297 mm，分页与预览一致，中文显示正常，文字和照片无意外截断 |
| 恢复项目 | 关闭后可继续编辑；从备份恢复时保留正文与布局，并能识别、重新关联缺失素材 |
| 百度网盘直连 | 经官方授权后可选取并导入照片或视频；只有实际验证通过才算完成此能力 |

**10. 开发前需要验证的事项**

| 事项 | 需要得到的结果 |
| --- | --- |
| 百度网盘接口 | 官方授权方式、目录和文件访问权限、照片与视频获取能力、配额及大文件限制 |
| 交付形式 | 比较桌面浏览器与桌面客户端在本地批量文件、持续访问、项目保存和打印方面的适用性 |
| 模型兼容 | 首批支持的接口、语音格式、长音频处理、图片理解及错误处理方式 |
| 素材格式 | 常见照片、视频和手机拍摄信息的读取、预览与导出支持情况 |
| 打印流程 | 中文字体、分页、图片清晰度、字体嵌入及典型家用打印效果 |

以上均为待验证事项，当前尚未完成接口或实现验证。应先用少量真实素材验证导入、回忆提取、排版及PDF这条完整流程，再扩展素材规模。

后续可考虑地图路线、在线分享、视频二维码和家人协作补充回忆；具体优先级根据第一版实际使用反馈确定。
